# Suika-like Merge Game — GDD

작성일: 2026-05-12
빌드 대상: Unity 2D (URP), PC (마우스 입력)

---

## 1. 개요

낙하한 과일이 같은 단계끼리 닿으면 한 단계 큰 과일로 합쳐지는 **물리 기반 머지 퍼즐**. 컨테이너 안에 과일이 쌓이며, 게임오버 라인 위에 정지하면 종료. 최종 단계 과일을 만드는 것이 1차 목표.

- 장르: 캐주얼 / 물리 퍼즐
- 플레이 시간: 1판 3–8분
- 입력: 마우스 (좌우 조준 + 클릭 드롭)
- 시각: 단일 Circle 스프라이트 + 단계별 색상 (에셋 최소화 컨셉)

---

## 2. 핵심 루프

```
   [조준]  →  [드롭]  →  [낙하/충돌]  →  [동일 단계 머지]
       ↑                                       ↓
       └──────────  [다음 과일 스폰] ←──────────┘
                              ↓
                  [게임오버 라인 정지 → 종료]
```

매 사이클은 1–2초. 플레이어는 "어디에 떨어뜨릴지" 한 가지만 결정하면 된다.

---

## 3. 조작

| 동작 | 입력 | 비고 |
|------|------|------|
| 좌우 조준 | 마우스 X 이동 | `minX = -2.3`, `maxX = 2.3`으로 클램프 |
| 드롭 | 좌클릭 | 스폰 쿨다운 0.5초 |

대기 중인 과일은 `spawnY = 4`에서 마우스 X 위치에 고정 표시 (Kinematic).

---

## 4. 과일 단계

전 단계 동일한 Circle 스프라이트에 색상·크기만 다르게 적용. 총 11단계.

| Stage | 지름 (units) | 색상 (RGB approx) | 머지 점수 |
|-------|-------------|--------------------|----------|
| 0 | 0.50 | 연분홍 | +10 |
| 1 | 0.70 | 주황 | +20 |
| 2 | 0.90 | 노랑 | +30 |
| 3 | 1.10 | 연두 | +40 |
| 4 | 1.35 | 민트 | +50 |
| 5 | 1.60 | 하늘 | +60 |
| 6 | 1.90 | 보라 | +70 |
| 7 | 2.20 | 핑크퍼플 | +80 |
| 8 | 2.55 | 핑크 | +90 |
| 9 | 2.90 | 빨강 | +100 |
| 10 | 3.30 | 진녹 (최종) | — |

- **스폰 풀**: 0–3단계만 자연 스폰 (`maxSpawnStage = 4`). 그 이상은 머지로만 등장.
- **최종 단계**: 10단계끼리 머지하면 양쪽 모두 제거되며 점수만 추가 (현 구현: 새 과일 생성 안 함).

---

## 5. 시스템

### 5.1 머지

- 두 과일이 충돌 시(`OnCollisionEnter2D`) 같은 stage이면 1단계 큰 과일로 합쳐짐.
- **중복 방지**: 두 과일 모두에서 충돌 이벤트가 발생하므로, `InstanceID` 비교로 한쪽만 머지 수행.
- 머지된 두 과일은 `merged` 플래그로 즉시 잠그고 제거. 새 과일은 두 위치의 중간점에 생성되며 즉시 Drop 상태.

### 5.2 점수

`score += (stage + 1) * 10` — 머지 시 합쳐지기 **직전** stage 기준. 큰 과일을 만들수록 누적 가속.

### 5.3 게임오버

- 드롭된 과일이 `gameOverY = 3.5` 위에 위치하고
- 속도 magnitude < 0.1 이며
- 드롭 후 2초 이상 경과

세 조건 모두 만족 시 종료. **드롭 직후 정지 오판 방지를 위한 2초 유예**가 핵심.

### 5.4 물리

- 중력 스케일: 2.5 (Rigidbody2D)
- 마찰: 0.4, 반발: 0.05 (`FruitMat.physicsMaterial2D`)
- 콜라이더: CircleCollider2D, radius = 0.5 (스케일로 크기 조정)

## 6. 씬 구성

```
                  ┌─────────────┐ ← spawnY = 4 (조준 위치)
                  │             │
              ────┤             ├──── gameOverY = 3.5 (빨간 라인)
                  │             │
                  │  (낙하 영역) │
                  │             │
                  │             │
                  └─────────────┘ ← floorY = -3.5
                  ↑             ↑
               x=-2.5         x=2.5  (벽)
```

- Camera: Orthographic, size 5, 위치 (0, 1, -10), 배경 진회색
- 벽/바닥/라인: Square 스프라이트 + Sliced drawMode
- 카메라 시야 (대략 ±8.9 × ±5) 안에 컨테이너 전체가 들어옴

## 6.1 UI
낙하영역 위에 왼쪽 스코어(Score : 점수), 오른쪽 다음 과일 표시
수박을 만들게 되면 게임 종료 창 표시 및 재시작 버튼 -> 버튼을 누르면 처음부터 시작
게임 오버 시 게임 오버 창 출력, 재시작 버튼 -> 버튼을 누르면 처음부터 시작

## 9. 파일 구조

```
Assets/
├── Sprites/
│   ├── Circle.png       (256x256, FullRect, 흰색 알파 페이드)
│   ├── Square.png       (4x4, 단색)
│   └── FruitMat.physicsMaterial2D
├── Prefabs/
│   └── Fruit.prefab
├── Scripts/
│   ├── Fruit.cs         (단일 과일 동작 + 충돌)
│   └── GameManager.cs   (스폰, 입력, 점수, 게임오버, 단계 테이블)
└── Scenes/
    └── SampleScene.unity
```

색상·크기 테이블은 `GameManager.cs`의 `stageColors`, `stageDiameters` static 배열에 일원화. 단계 추가/조정은 이 두 배열만 수정하면 됨.
